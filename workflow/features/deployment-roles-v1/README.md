# Deployment roles v1 workflow

Status: completed

This feature defines router-only, switch-only, and converged router-switch as
profiles of one full-featured Bifrost product and management plane.

Scope:

- add BFW-PRD-100 through BFW-PRD-105
- add machine-readable deployment profiles and a strict public schema
- define role-specific enabled and denied forwarding effects
- define non-transit switch management addressing and safe role transitions
- preserve narrow v0.1 and platform/hardware admission boundaries

No runtime code, component repository, release, external action, or product
admission is authorized by this workflow.
