# Security policy

GOTTH Bifrost is currently design/governance work, not a supported runtime
release. No version is admitted for production network enforcement.

Report suspected vulnerabilities privately through:

https://github.com/gotthboard/gotth-bifrost/security/advisories/new

Do not publish vulnerabilities, exploit details, credentials or sensitive
configuration in public issues, pull requests or discussions. Forgejo is the
canonical source host, not a bug or security reporting endpoint.

For non-security bugs use:

https://github.com/gotthboard/gotth-bifrost/issues

Include the relevant source revision, affected contract and a redacted
reproduction. Do not include reusable credentials or private network captures.
