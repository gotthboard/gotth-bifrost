# Bifrost component bootstrap template

Copy this directory only when the meta repository authorizes creation of one
component repository. Replace every `{{PLACEHOLDER}}`; retain the canonical
PRD → architecture → implementation-spec order; and keep evidence honest.

Required files:

- `documents/PRD.md`
- `documents/ARCHITECTURE.md`
- `documents/IMPLEMENTATION-SPEC.md`
- `documents/THREAT-MODEL.md`
- `compatibility.toml`
- `TEST-PLAN.md`
- `evidence.toml`
- `release.toml`
- `INDEPENDENT-REVIEW.md`

A template copy grants no Bifrost authority or release admission.
